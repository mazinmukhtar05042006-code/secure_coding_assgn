⚠️ SECTION B: What Went Wrong?
  • Supply Chain Blindness: Relying on external code without checking for published CVEs.
  • Dependency Bloat: Installing unneeded packages increases the codebase's exploitable surface.
  • Missing Lockfiles: Unpinned dependencies allow malicious or vulnerable sub-dependencies to be pulled in dynamically.

🎯 SECTION E: Secure Coding Principle

Minimize Attack Surface & Defense in Depth: Reducing external dependencies removes code paths that attackers could exploit, and regular SCA testing ensures that inherited vulnerabilities are identified and remediated immediately.

Why does this matter in real systems?

Over 80% of code in modern applications comes from open-source dependencies (OWASP A06:2021). Compromised or unmaintained packages (e.g., Log4Shell, event-stream) allow supply-chain attackers to hijack applications without exploiting application logic.
