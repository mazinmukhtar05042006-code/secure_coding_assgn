Improper Exception Handling

Generic bare except: blocks mask underlying bugs and expose sensitive internal system tracebacks to end users.

⚠️ SECTION B: What Went Wrong?
  • Information Leakage: Raw stack traces exposed server absolute paths, python filenames, and function names.
  • Bare Exception Anti-pattern: Generic except: catches system interrupts, preventing graceful shutdown.
  • Resource Leaks: Swallowed exceptions bypassed necessary file and socket cleanup routines.
⚖️ SECTION D: Before vs After Fix
❌ Vulnerable Approach
❌ Bare except: catch-all
❌ Raw tracebacks returned to clients
❌ Server directory structure exposed
❌ Unhandled resource leaks
✓ Secure Implementation
✓ Specific typed exception handlers
✓ Sanitized user-facing messages
✓ Full diagnostic logs kept server-side
✓ Guaranteed cleanup via with context
🎯 SECTION E: Secure Coding Principle

Fail Securely & Secure Recovery: Applications must fail gracefully without exposing sensitive implementation details or granting unauthorized state, while guaranteeing resources are released.

Why does this matter in real systems?

Stack traces act as a roadmap for attackers (CWE-209), revealing underlying libraries, versions, and database query structures that make automated exploitation significantly easier.
