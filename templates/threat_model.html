💎 Protected Assets
  • Host Shell & Processes: Server OS execution integrity and CPU control.
  • Application Source & Config: Backend python scripts and .env tokens.
  • User Credentials: Authentication hashes and session identity.
  • Server Diagnostics: Internal stack traces, directory layouts, and logs.
🌐 Trust Boundaries & Threat Actor
  • Threat Actor: Generic remote unauthenticated / malicious web user.
  • External Web Boundary: HTTP GET/POST form parameters and headers.
  • Filesystem Boundary: File reading sandbox and temporary directories.
  • OS Execution Boundary: Process invocation API (subprocess).

🎯 STRIDE Threat Identification Cards

Tampering / Elevation of Privilege CRITICAL
Affected Weakness: Vulnerability 1 (OS Command Injection)
Attack Vector: Submitting command chaining tokens (; && |) in input.
Mitigation: Strict allowlist validation + subprocess.run(shell=False).
Information Disclosure HIGH
Affected Weakness: Vulnerability 2 (File Path Traversal)
Attack Vector: Supplying dot-dot-slash sequences (../) to escape web root.
Mitigation: Canonical path resolution + Path.is_relative_to(base).
Spoofing / Credential Theft CRITICAL
Affected Weakness: Vulnerability 3 (Plaintext Passwords)
Attack Vector: Extracting stored cleartext credentials during database breach.
Mitigation: Salted PBKDF2/scrypt hashing + constant-time verification.
Information Disclosure MEDIUM
Affected Weakness: Vulnerability 4 (Improper Exceptions)
Attack Vector: Inducing runtime errors to view leaked filesystem stack traces.
Mitigation: Specific exception handlers + sanitized user-facing messages.
Tampering / Race Condition MEDIUM
Affected Weakness: Vulnerability 5 (Predictable Temp Files)
Attack Vector: Symlink pre-creation and TOCTOU collision in shared temp space.
Mitigation: High-entropy NamedTemporaryFile with automatic disposal.
Elevation of Privilege HIGH
Affected Weakness: Vulnerability 6 (Unmanaged Dependencies)
Attack Vector: Exploiting known public CVEs in outdated third-party packages.
Mitigation: Minimal package manifest + continuous SCA auditing.
