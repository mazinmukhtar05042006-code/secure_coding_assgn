⚠️ SECTION B: What Went Wrong?
  • Naive Joining: os.path.join() does not neutralize relative directory tokens (../) or absolute paths.
  • No Boundary Check: The application opened whatever path was provided without verifying if it remained inside the sandbox.
  • Information Exposure: Source code and configuration files outside the approved directory were disclosed.

🎯 SECTION E: Secure Coding Principle

Complete Mediation & Secure by Default: Every single access request to a file resource is fully inspected, canonicalized, and verified against an approved base directory before access is granted.

Why does this matter in real systems?

Path traversal (CWE-22) allows attackers to download backend secrets, database connection strings, API private keys, and environment variables (.env), which are then used to orchestrate severe follow-up exploits.
