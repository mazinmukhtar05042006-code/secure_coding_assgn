⚠️ SECTION B: What Went Wrong?
  • Cleartext at Rest: Passwords were stored directly as readable strings in memory and storage.
  • Zero Leak Protection: Any database backup leak, SQL injection, or insider inspection immediately compromises all accounts.
  • Credential Reuse Risk: Users frequently reuse passwords across critical personal and financial services.

✓ Secure Implementation
✓ Salted PBKDF2/scrypt key derivation

🎯 SECTION E: Secure Coding Principle

Secure Data Handling & Defense in Depth: Sensitive credentials are protected at rest using one-way cryptographic algorithms with unique salts, ensuring passwords cannot be reconstructed even if storage is breached.

Why does this matter in real systems?

Plaintext password storage is a direct violation of international compliance standards (GDPR, PCI-DSS, NIST 800-63B). Salted slow key derivation prevents dictionary and rainbow table cracking.
