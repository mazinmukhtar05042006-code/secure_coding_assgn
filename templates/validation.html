📋 Active Validation Rules Allowlists
1. Hostname / IP: Validates strictly against IPv4/IPv6 address grammar or RFC domain regex. Blocks all command chaining tokens.
2. Username: Length: 3–30 characters. Allowlist pattern: ^[a-zA-Z0-9_-]+$.
3. Password: Length: 8–128 characters. Requires at least 1 uppercase letter, 1 lowercase letter, and 1 numeric digit.
4. Filename: Max 100 chars. Regex: ^[a-zA-Z0-9_.-]+$. Completely forbids /, \, .., and null bytes.
⚖️ Server-Side vs Client-Side Validation
❌ Client-Side Only (Insecure)
❌ Trivially bypassed via curl / Burp Suite
❌ Browser controls do not provide security
❌ Never trust client assumptions
✓ Server-Side Enforcement (Secure)
✓ Mandatory inspection on every request
✓ Strict allowlists over fragile blocklists
✓ Multi-layered (Type, Length, Format, Range)
